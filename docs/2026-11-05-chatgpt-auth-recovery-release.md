# ChatGPT 授权配置读取修复 0.18.2

用户看到的“ChatGPT 授权配置无法验证，请重试”来自登录或刷新凭据前读取公开 OIDC 配置的步骤。原实现会将连接失败、超时、HTTP 错误、无效 JSON 和配置字段错误合并成这一条提示，掩盖实际失败阶段。

排查时通过本机系统代理读取官方配置得到 HTTP 200。空白隔离 Zotero 10.0.7 中，0.18.1 的真实请求和生产 AuthManager 校验同样通过。已安装的日常插件为启用的0.18.1。用户随后反馈问题已恢复，推测此前未接通 VPN，这与授权服务连接失败的现象一致。

新版按失败阶段显示具体错误，HTTP 错误带状态码，配置校验错误给出字段名。错误消息采用固定文字，避免把服务端响应正文或底层连接详情直接显示到设置中。公开配置 GET 遇到连接失败、超时或 HTTP 408、500、502、503、504 时，等待300毫秒后重试一次，并发调用共享这一轮读取。单次请求上限为20秒，持续失败时两次请求合计最多约40秒。

身份验证继续使用官方配置中的授权端点、令牌端点和公钥地址，校验发行者与端点来源，并拒绝端点中的用户名、密码或片段。注册、PKCE、身份令牌和作用域验证依照官方登录流程。[OpenAI 授权配置文档](https://developers.openai.com/siwc/website)与[注册和登录文档](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)

覆盖安装0.18.2后，完全退出并重启 Zotero。在“设置→页边批注→ChatGPT 订阅”点击“Continue with ChatGPT”。如果仍遇到连接问题，设置页会保留本次失败的具体提示，便于继续定位。
