# 使用指南

本指南面向 Zotero Margin Assistant 0.20.0。项目用途和功能概览见 [README](../README.md)，各版变化见 [更新日志](../CHANGELOG.md)。

## 安装与升级

插件支持 Zotero 桌面版 10.0.x，主要在 Windows 上验证。从 [最新 Release](https://github.com/Yuxuan-Liang-git/zotero-margin-assistant/releases/latest) 的 Assets 下载 `.xpi`，在 Zotero 的“工具 → 插件”中，通过右上角齿轮菜单选择“从文件安装插件”。已有版本直接覆盖安装，然后完全退出并重新打开 Zotero，无需先卸载。文档助手和页边批注功能无需安装浏览器的 Zotero Connector。

打开 PDF 后，从阅读器工具栏打开文档助手或 Notion 栏。插件设置位于“设置 → 页边批注”，服务配置和阅读外观集中在这里。若升级后仍显示旧界面，先确认插件管理器中的版本，并检查 Zotero 是否已经完全退出后重开。

## 选择和配置 AI 服务

### DeepSeek API

在插件设置的文档助手区域选择 DeepSeek，填写自己的 API Key，再点击“应用设置”。密钥通过 Zotero 的系统密钥库加密保存在本机，重启后恢复。输入框留空再应用只调整其他设置；“清除密钥”会删除保存的密钥。连接测试获取模型列表，不发送 PDF。当前默认模型为 `deepseek-flash`，接口使用 `https://api.deepseek.com`。

### ChatGPT 账户授权

在设置中点击“Continue with ChatGPT”，通过系统浏览器的 OpenAI 官方页面登录并授权，再回到 Zotero 选择“ChatGPT 订阅”。该方式无需 OpenAI API Key；可用账户、工作区和模型以授权后返回的目录为准。登录凭据加密保存在本机，并支持刷新、退出及重启恢复。

该接入使用 Codex / ChatGPT Work 的共享订阅额度，会与相应工作额度共同计量。模型、速度、思考档位及联网能力取决于账户资格和服务实际返回结果，参见 [官方订阅接入说明](https://developers.openai.com/siwc/token-sharing-open-source)。插件中的聊天按 PDF 保存在本地，与 ChatGPT 网页聊天分别保存；授权不会读取网页历史或同步网页记忆。

可在设置中选择模型支持的思考强度和生成速度。快速档位会增加共享额度消耗，服务端拒绝可选参数时会提供显式重试入口，点击后才重新发送。回答结束后，如服务返回实际速度档位，界面会显示该结果。切换服务会继续使用当前会话；需要独立上下文时，可新建会话。

### 外观、自定义提示词与联网

“阅读外观”提供 12–24 px 字号，默认 14 px，作用于助手正文、公式和输入框。自定义提示词可保存、留空或恢复默认，并用于后续聊天与阅读摘要。设置会在重启后保留。

ChatGPT 可按需联网检索，设置中可调整联网搜索与检索配图。模型会自行判断是否调用搜索，实际能力受模型和账户权限约束。检索结果中的链接和配图保留出处；配图直接连接公开 HTTPS 地址，加载失败时保留来源链接。普通 Markdown 远程图片不会自动加载。DeepSeek 继续使用文档材料进行对话。

## 针对当前 PDF 提问

打开文档助手即可输入问题，插件会自动准备当前 PDF 的材料。Enter 发送，Shift+Enter 换行；输入法选字期间的 Enter 保留给输入法。生成过程中可停止，完整回答支持 Markdown 和 LaTeX。回答结束后默认定位到本次回答开头；如果已经滚动或选中文字，则保留阅读位置。

ChatGPT 对不超过 20 页、原文件不超过 6 MiB 且编码后能放入本轮预算的文档，每轮尝试附带完整 PDF。自动材料预算约为 4 MiB，包含编码膨胀，因此实际可附带的文件可能小于 6 MiB。其他情况使用文字层或相关片段，并补充当前页和少量相关页图像，自动页图最多三页。界面会显示实际输入范围及省略原因。

图片公式可能不在文字层中。讨论这类公式时，可翻到对应页、说明 PDF 实际页码，或手动框选目标区域；完整 PDF 模式会携带全部页面，片段模式的视觉依据仅限实际附带的图像。纯扫描件尚无整书 OCR 或自动公式编号索引。

关闭侧栏只隐藏界面，问答和草稿仍保留。重新打开后，下一次提问会再次加入当前 PDF 材料。整份文件只随最新问题提供，文件编码不会写入历史 JSON；本地记录文件名、大小和页数供核对。自动页图每轮刷新，旧自动图不重复发送。

### 添加附件与批注提问

在输入区按 Ctrl+V 粘贴截图或复制的文件，也可通过附件按钮选择，或直接拖入 PDF、PNG、JPEG、WebP。单文件上限为 6 MiB，每轮附件和区域合计最多八项，完整请求还受约 12 MiB 的本地预检限制。ChatGPT 接收 PDF 和图片，DeepSeek 当前接收图片；不支持的附件会明确提示。

待发送附件先保存到当前 PDF 同目录的 `margin-comments-chat-files/`，点击发送时才提交。移除待发送项不会删除原文件或已保存副本，副本需要自行备份。

选中回答文字后，可右键“引用并批注提问”，在原文旁的气泡写下注释。PDF 选中文字或已有高亮、下划线、框选区域也有相应的批注提问入口。点击外部会收起气泡，空批注自动移除；有内容的批注保留编号图标，点击可重新编辑。最多可暂存二十条批注，一次发送时将引用、批注和输入框问题一起提交。

批注草稿按 PDF 和会话保存，关闭、切换或重启后可恢复。发送失败时保留草稿，成功后清空待发送气泡，引用和批注继续保存在已发送的问题中。单条引用最多 12000 字符，批注最多 4000 字符，整体请求仍需满足容量限制。

### 输入、复制与公式

输入框支持方向键移动、Shift 选择、Ctrl 按词移动和 Home/End。拖动输入区上沿的短横线可调整高度，向下拖到底可完全收起；双击横线恢复默认高度，也可聚焦手柄后用方向键调整、Enter 恢复、Home 收起。收起时保留草稿和光标。

选择回答中的文字后可直接复制。选中渲染公式的任意部分后复制，默认得到完整 LaTeX 源码和原分隔符；混选时保留普通文字并将公式还原为 LaTeX。公式右键的“复制公式 LaTeX”无需先选择，回答下方的“复制”复制整段 Markdown 和 LaTeX。该能力处理已有公式渲染内容，PDF 截图中的公式需要图像识别后才能得到源码。

流式回答会按完整内容块节流渲染公式。尚未闭合的公式先显示原文，闭合后渲染；选中文字时会暂缓重绘，减少复制过程中的干扰。

## 会话管理与导入导出

每份 PDF 有自己的会话列表。“新会话”建立独立讨论，“对话记录”切换该 PDF 下的会话与草稿。文献下的“DeepSeek 对话历史”入口可打开对应 PDF 的助手。新会话不继承上一段问答，每轮仍会读取当前 PDF。

在对话记录中选择“导入对话”，可读取解压后的 ChatGPT `conversations.json`、插件导出 JSON 或已有本地历史 JSON，也可直接粘贴带角色标记的问答。多段对话可按标题筛选，有分支时选择相应路径；预览后为当前 PDF 新建会话，原有记录保留。最后一条未回答的问题放入输入框草稿。

粘贴文本需有明确角色，例如：

```text
用户：
如何理解公式 (6.30)？
助手：
已有的解释，包含公式 \(y=Hu+e\)。
用户：
接着解释其中的假设。
```

也支持“你说 / ChatGPT 说”“You / ChatGPT”和“You said / ChatGPT said”等标记；代码围栏中的同名文字不会作为角色边界。无角色文本需先补齐角色。导入只接收用户和助手可见文字，隐藏推理和工具日志不导入，网页上传的附件需要重新添加。

导入上限为 16 MiB JSON、二百条问答消息、单条十万字符、单段一百万字符；粘贴框最多约二百万字符。超限会提示，正文不会静默截断。ZIP、网页 HTML、分享链接和 Markdown 文件暂不支持直接导入。

“导出 JSON”用于再次导入，“导出 Markdown”用于阅读归档，均保留公式源码和未发送草稿。导出不包含 PDF 或图片附件字节、批注气泡草稿及本地来源关联。相关格式与限制见 [导入导出设计说明](2026-10-26-conversation-transfer-proposal.md)。

## 标记和引用前文

在前文框选公式、图表或段落，右键“标记为引用来源”，输入类型与编号，例如公式 `6.30`。文字可直接选中后标记，也可使用已有高亮或下划线。到目标页边批注中选择“插入引用”，输入编号，核对候选页码后插入；编号重复时会列出多个来源。

引用会沿用目标批注的显示侧。鼠标停在来源链接上可查看前文公式、图片或文字预览，浮层会优先使用页面空白位置；可以继续跳转原文或加入提问。PDF 实际页码与书内页码分别保存。已有批注还可通过“引用选中文字到页边批注”直接插入文字，并建立可回溯的高亮来源。

来源移动、删除或文件变化后，插件会提示重新定位。可在引用目录中使用“重新关联”，再选定正确区域。失效的历史材料本轮会省略，原问答保留；有效文档材料仍可参与对话。请结合界面的输入范围确认模型实际收到了哪些内容。

## 页边公式与图片

页边批注和 PDF 原生“新增文字”可使用 `\(...\)` 行内公式和 `\[...\]` 独立公式。例如：

```latex
参数满足 \(y=Hu+e\)。

\[
\begin{aligned}
e &= y-Hu \\
\frac{\partial e}{\partial\theta}
  &= -\frac{\partial H}{\partial\theta}u
\end{aligned}
\]
```

独立公式中的直接换行 `\\` 也可显示为多行，已有对齐和矩阵环境会保留结构。原生“新增文字”结束编辑后在页面原位置渲染，再次编辑时恢复源码；不会重复生成页边卡片。原始 LaTeX 保存在原生批注中，公式显示由插件提供，导出到其他阅读器后的文字批注仍可能显示源码。

在页边批注中 Ctrl+V 粘贴截图、拖入本地图片，或点击“插入图片”选择文件。支持 PNG、JPEG、GIF、WebP，每张最多 10 MiB。图片保存在 PDF 专用的 Zotero 图片笔记和嵌入附件中，同时在 PDF 同目录的 `margin-comments-images/` 保存副本；仅有图片的批注也能在重开后恢复。

点击图片或“查看原图”可打开查看器，支持适应窗口、100% 原尺寸、缩放和拖动平移，Esc 关闭。“打开图片笔记”可查看对应 Zotero 笔记；PDF 有父文献时，笔记位于该文献下。

## 在 PDF 页面放置和导出图片

在 PDF 页面右键可插入或粘贴图片，也可聚焦页面后 Ctrl+V，或直接拖入本地图片。页边已有图片可通过“放到 PDF 页面”复用。选中图片后可拖动、等比缩放、锁定或移除页面放置，位置随本地数据保存，重开后恢复。

右键“导出带图片的 PDF”，选择新的文件位置，即可将原生标注和页面图片写入一份独立 PDF。导出使用开始时的位置快照，在后台处理并支持取消。原 PDF 继续用于调整页面图片，导出文件用于在其他阅读器查看。具体操作与边界见 [页面图片说明](2026-11-05-page-images-release.md)。

0.19.0 页面图片使用版本3存储格式，首次使用会保存迁移备份。回退旧版本前应备份现有 JSON、图片副本和导出文件。

## 阅读摘要与个人文献库记忆

“阅读摘要”汇总当前 PDF 多段会话中已澄清的文章内容、关键公式解释和补充讨论，维护一份可独立阅读的 Zotero 笔记。完整回答结束并空闲二十秒后，自动整理会判断是否需要更新；没有新理解时保持原文。也可手动更新或重新整理，重开时直接读取本地已有笔记。

自动摘要使用当前 AI 服务额度，可在设置中关闭。检测到人工改写时保留原文，新整理结果可作为候选版本另存；生成失败不清空正文和进度。摘要与聊天的上下文压缩分别维护，完整问答仍保存在本地。

个人文献库记忆在本地索引书目信息、PDF 正文、Zotero 笔记、文字标注，以及已有对话和正式阅读摘要。尚无对话记录的论文也可被检索。每次只按问题和上下文预算引入相关片段，并提供来源入口；设置中可查看覆盖状态、暂停、继续、重建和导出研究笔记。

跨文档记忆将检索到的来源片段加入本轮请求。当前 PDF 的正文仍单独准备；其他文献按问题和可用预算进入上下文。最多引入三篇论文、每篇两段，单段最多 1800 字符，研究记忆整体预算约 6000 字符，来源信息也占用预算。正文、正式摘要和历史助手解释会保留各自身份与入口。通用整篇概述、纯符号和公式编号追问会跳过无明确主题的跨文献检索。

### 配置 Embedding 服务

云端语义检索使用独立的 Embedding API Key。请在 Zotero 的“设置 → 页边批注 → 云端语义检索”中填写自己的 Key；DeepSeek 对话 Key 与 ChatGPT 登录不会自动提供 Embedding 权限。默认服务的完整端点是 `https://api.siliconflow.cn/v1/embeddings`，模型是 `BAAI/bge-m3`。选择自定义时需填写完整的兼容 HTTPS Embedding 端点与准确模型名。服务价格、额度和限速请以服务方账户为准，插件不会自动切换收费模型。

点击“保存配置”，再点击“测试连接”。测试只发送固定短句，不发送文献内容。成功后勾选启用，再主动点击“试建 20 篇”。试建覆盖最多二十篇，适合先确认来源、文字覆盖、账户费用和中文问题的召回效果；资料变化后需再次明确试建或建立全库。安装插件、保存配置、测试连接或打开 PDF 都不会授权首次全库上传。需要更完整覆盖时点击“建立／继续全库索引”。

每个完整 HTTPS 端点保存自己的配置与加密 Key。切换至从未保存过的新端点后，空密码框不会沿用原端点密钥；返回已保存端点时恢复其配置。同一端点的空密码框表示保留已保存密钥，“清除本端点密钥”只清除该端点的 Key。模型、端点和实际向量维度共同区分检索空间，换服务后需要为对应空间重新建立索引。

### 建立、暂停与核对覆盖

默认每条 Embedding 输入最多 8000 UTF-8 字节，每批最多八条，后台每分钟最多二十次请求。请求批次可能少于八条；首次大型文献库建立可能持续数小时。例如七万条输入即使每批恰好八条、请求持续达到默认上限，也需要约七小时十八分钟，提取、片段划分、限速和重试还会增加时间。具体用量由服务方计费规则决定。

当前打开的 PDF 会获得后台处理优先级。对话请求进行时，新的后台批次会让出资源。“暂停后台任务”保留已经有效的向量；点击继续可复用已完成输入。未完成任务在重启后保持暂停，需明确继续。试建、暂停和未覆盖的论文意味着部分覆盖，界面中的就绪来源数不能解释为整库已完成。

向量材料来自已提交的文献信息、可提取的 PDF 正文、普通 Zotero 笔记、文字标注、合格正式阅读摘要和完整问答。草稿、待整理正文、未完成回答、历史检索来源缓存和 Notion 网页不参与 Embedding。旧的纯文本摘要如果缺少可核对的原生笔记身份，会保留原数据并等待核验，不会直接作为云端材料。

PDF 自动正文提取上限为 64 MiB，大文件优先使用已有缓存。纯扫描件需要先在其他工具中完成 OCR；图片公式、图表和未识别文字可能没有向量覆盖。向量匹配提供相关候选，最终仍核对来源是否有效。点击来源可回到原文页、原笔记或历史会话；请检查原文条件后再用于科研判断。

### 云端、本地与回退

Embedding 服务接收需要建索引的文字并返回向量。本机独立的 `margin-comments-assistant/research-memory/vectors-v1.sqlite` 保存派生向量、来源关联与任务进度；原来的 `papers-v1.sqlite` 继续保存本地正文索引。本地 Worker 分批扫描向量，结合词面检索与来源有效性筛选；每轮只将实际选中的片段发给对话服务。Notion 网页继续由独立阅读栏打开，内容不会自动进入 AI 材料。

“清除派生向量索引”清除当前端点、模型和维度空间中的派生索引及任务进度，不删除 PDF、原始会话、阅读摘要或本地正文索引。重建需要再次明确开始，并可能重新消耗 Embedding 额度。向量索引需要自行备份，不承诺通过 Zotero Sync 同步。

语义检索给本轮前台增加的预算为八秒。无密钥、服务不可用、断网或超过预算时，插件使用仍有效的本地检索结果，保留当前 PDF 材料和普通对话。没有可靠候选时可以不加入跨论文来源。向量语义匹配仍可能误召回或遗漏；默认最低余弦阈值 0.45 是起始设置，尚未针对真实服务校准。

当前受控自动化验证连接、加密、冷重启、跨语言来源注入、跳页、Worker 和回退流程。它使用自编 PDF 与确定向量，没有调用真实 Embedding 服务或推理服务。真实中英文语义质量、学术相关性、额度和网络延迟，需要用户在 Zotero 填入自己的 Key 后核对。验证范围见 [0.20.0 说明](2026-11-10-cloud-rag-release.md)，原本地索引机制见 [个人文献库记忆](2026-11-04-personal-library-memory-release.md)。

## 同时阅读 Notion 笔记

插件复用文献下已有的 Notion 链接，例如 [Notero](https://github.com/dvanoni/notero) 创建的链接。点击阅读器 Notion 图标后，首次在页面中登录；多个关联页面可从栏目“⋯”菜单切换。文献信息向 Notion 的同步仍由原有工具负责，无需为本插件另填 Notion API。

Notion 和文档助手是独立栏目，可以同时打开、单独关闭和调宽。拖动标题栏到窗口目标半边可调整左右位置，拖动各栏内侧边缘调整宽度；聚焦标题栏后 Alt 加左右方向键也可切换位置。位置和宽度会保存，PDF 内 Ctrl+F 搜索框保留在阅读区域。Notion 网页内容不会自动加入 AI 输入。

## 本地数据、备份与请求限制

会话、草稿、编号引用、阅读摘要状态和页面图片位置位于 PDF 同目录的 `margin-comments-assistant-<libraryID>-<attachmentKey>.json`。旧数据首次迁移时保留原文件，已有新版 JSON 优先使用。聊天附件位于 `margin-comments-chat-files/`，图片副本位于 `margin-comments-images/`。这些同目录文件及 Zotero 数据目录中的本地研究索引需要自行备份，不承诺通过 Zotero Sync 同步。

独立阅读摘要和图片笔记由 Zotero 管理；嵌入图片的同步占用 Zotero Storage 配额，参见 [官方笔记说明](https://www.zotero.org/support/notes)。AI 凭据经 `OSKeyStore` 加密保存在本机 Zotero 首选项中，不写入 PDF 旁 JSON、笔记或源码。

发送问题时，当前文档、手动材料、历史问答及被检索到的片段会按本轮范围提交给所选服务。启用自动摘要后，整理讨论也会调用服务。页边笔记中的图片不会自动加入聊天；ChatGPT 联网检索可能将问题和论文主题组成检索词提交搜索服务。

本地预检约束包括每轮八个附件或区域、截图最长边最多 2400 像素、整体请求约 12 MiB、文字约六万字符。文档文字预算最多约 24000 字符。长历史按尚未压缩部分的体积触发承接摘要，保留近期原文与完整本地记录；压缩失败会保留原始问答。

网络中断、模型限制或服务拒绝仍可能导致回答未完成。可保留草稿和部分回答，查看错误说明后再决定重试。反馈时提供 Zotero 和插件版本、复现操作及脱敏诊断，请隐藏密钥和私人文档内容。当前安装包采用手动升级方式，更新入口位于 [GitHub Releases](https://github.com/Yuxuan-Liang-git/zotero-margin-assistant/releases)。
