# 页边批注粘贴与拖入图片

用户已选择在页边批注中按Ctrl+V粘贴截图，并支持拖入图片。保存方式沿用此前已确认的Zotero图片笔记和PDF同目录副本。此次变更交付0.18.1。

### 交互与范围

批注卡片捕获图片粘贴和文件拖放事件，复用现有图片保存与展示流程。图片显示在对应批注的图片区域，正文中的文字、LaTeX和光标交由原编辑器处理。多张图片按顺序保存，每张导入结果可检查。已有“插入图片”文件选择按钮使用相同流程。

图片格式为PNG、JPEG、GIF和WebP，每张上限10 MiB。优先读取粘贴事件的文件对象，Gecko未暴露文件时使用已有本机剪贴板读取接口。拖入本地图片读取文件内容，通过文件头验证格式。资料中的URL作为文字资料处理。

### 实现选择

图片事件单独放在 `src/margin-images.js`，监听范围为当前批注卡片，使用捕获阶段处理图片事件以兼容现有编辑器停止冒泡的行为。通过原生paste事件处理Ctrl+V、菜单粘贴，避免一次操作走两条导入路径。普通文字事件继续交给原编辑器。

`ImageManager.importImage` 接受原有文件路径和Blob/File/字节输入，文件读取复用附件管理器已有的FileReader适配，图片保存继续采用独立副本、原生嵌入附件、笔记正文和本地关联记录。目标批注在异步读取后与提交前再次验证，失败回滚本次产生的资料。停用时等待图片队列结束。

### 备选方式

用户选择了在卡片中直接粘贴及拖入的交互。现有文件选择按钮适合浏览本地目录，继续作为可见入口。将图片编码直接写入批注正文会放大正文并影响现有公式编辑，因此本次使用已有图片区域与持久化记录。

### 验证

单元测试覆盖内存图片、外部窗口ArrayBuffer、错误格式、超限、只读、异步删除目标、停用与回滚。浏览器通过卡片事件入口覆盖图片粘贴、拖入多图、文字和公式粘贴、重复绑定与重建恢复。隔离Zotero使用真实嵌入图片和同目录文件验证首次启动与冷重启，剪贴板输入使用本地夹具回调，保存用户的系统剪贴板状态。完成完整回归、全源码类型检查及确定性XPI打包。
