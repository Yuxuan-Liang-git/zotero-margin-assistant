# PDF 图片阅读、放置与导出 0.19.0

### 安装与原图阅读

在 Zotero 的“工具 → 插件 → 从文件安装插件”中选择 `margin-comments-deepseek-0.19.0.xpi`，直接覆盖现有版本，再完全退出并重新打开 Zotero。无需先删除旧插件。适用于 Zotero 10.0.x。

页边批注中的图片继续作为缩略图显示。点击图片或“查看原图”，即可打开阅读器内的大图查看器。默认适应窗口，可切换到100%原尺寸，使用按钮或滚轮缩放，按住图片拖动平移。点击关闭或按 Esc 返回批注。与 Notion 并排阅读时，大图和导出进度会临时显示在网页上方，关闭后恢复原 Notion 页面。

### 在 PDF 页面放置图片

在 PDF 页面右键，选择“在此插入图片”或“在此粘贴图片”。也可点击 PDF 页面后按 Ctrl+V 粘贴截图，或把本地图片拖到页面。页边批注、文档助手和 Notion 中的粘贴仍由各自的输入区处理。已有批注图片可通过“放到 PDF 页面”直接复用。

支持 PNG、JPEG、GIF、WebP，每张图片最多10 MiB。图片初始保持原始宽高比。点击页面图片后，可拖动调整位置，拖动右下角手柄等比缩放；选中控件中的“锁定”会固定位置和尺寸，解锁后可再次调整。选中后使用方向键微调位置，聚焦缩放手柄后使用方向键微调尺寸。拖动中按 Esc 取消本次调整。

图片限制在所属页面内，可在一页放置多张图片，也可多次放置同一图片资产。点击页面空白处收起控件。“移除页面图片”仅移除这一处放置，已保存的图片笔记和副本仍可查看。图片位置、大小和锁定状态在重新打开 PDF 或重启 Zotero 后恢复。只读资料保留查看功能，修改操作会提示原因。

### 保存与导出

图片同时保存在该 PDF 专用的 Zotero 图片笔记，以及 PDF 同目录的 `margin-comments-images/`。页面放置保存在同目录的 `margin-comments-assistant-文献库ID-附件Key.json` 的 `pageImages` 中，使用 PDF 原始坐标记录位置，与窗口缩放独立。

首次产生页面图片时，本地数据升级到版本3。发布前会逐字节备份旧版本2文件到 `.v2.bak`；版本1仍沿用原有迁移备份。旧版本插件不能正确维护新页面位置，应继续使用0.19.0或后续兼容版本。已有对话、摘要、引用和批注图片保留。PDF 文件被替换或原页码失效时，保留图片资产并提示重新放置。

在 PDF 右键菜单中选择“导出带图片的 PDF”，选择一个与原 PDF 不同的文件路径。导出先包含 Zotero 原生标注，再将页面图片合成到新文件中，其他 PDF 阅读器也可显示。原 PDF 继续用于日后调整图片，导出件保存该次开始时的位置快照。GIF 导出首帧，WebP 与带 EXIF 方向的 JPEG 会按实际显示方向转成静态图像。

导出在独立 Worker 中合成，显示处理进度并支持取消。取消或失败时清理本次临时文件；写入完成后才发布目标文件，原 PDF 路径受到保护。若图片或位置在导出期间发生变化，重新导出即可包含最新调整。
