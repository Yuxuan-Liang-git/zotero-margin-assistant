# 页边批注图片输入 0.18.1

### 使用方式

覆盖安装 `margin-comments-deepseek-0.18.1.xpi` 后，完全退出并重新打开 Zotero。在 PDF 页边批注中进入正文编辑，将光标放入批注后按 Ctrl+V，即可粘贴剪贴板中的截图。也可以把一张或多张本地图片拖到对应批注卡片，拖入时卡片出现边框提示，松开后依次保存。底部的“插入图片”按钮同样可以选择文件。

图片显示在对应批注的图片区域，支持 PNG、JPEG、GIF 和 WebP，每张上限10 MiB。批注底部显示已插入数量或具体失败原因，多图导入按顺序处理。文字和公式粘贴继续由正文编辑器处理，只读资料会显示相应提示。

### 本地保存

每份 PDF 使用一份专用 Zotero 图片笔记，其中保存原生嵌入图片和来源页链接。在批注图片下点击“打开图片笔记”即可查看。有父文献时笔记放在该文献下，独立 PDF 使用带来源链接的独立笔记。

图片副本保存在 PDF 同目录的 `margin-comments-images/`，图片与批注的关联写入该 PDF 旁的 `margin-comments-assistant-<libraryID>-<attachmentKey>.json`。仅含图片的空白高亮批注在重新打开 PDF 后也会恢复。原生笔记及嵌入附件由 Zotero 管理同步，PDF 旁的副本和关联文件需随本地文件管理。

### 实现与验证

图片输入复用既有保存流程，监听范围限定在当前批注卡片。导入队列按 PDF 串行处理，在异步读取后和提交前重验目标批注，保存失败时补偿本次产生的文件与附件。卡片重建时恢复显示，重复装饰同一张卡片只绑定一组输入事件。

独立审查发现仅含图片的空白批注可能在重新打开后隐藏，已补失败回归并修复。原生验收还发现已有全文缓存按页定位的问题，补充测试后，具有可靠分页标记的缓存可保留原页号。
