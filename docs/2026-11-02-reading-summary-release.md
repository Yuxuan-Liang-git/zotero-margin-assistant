# 0.14.0 阅读摘要

### 使用与保存

每份 PDF 维护一份跨会话的阅读摘要，重点回顾追问过的难点、推导条件、公式联系、已经澄清的理解及待核对问题。助手顶部的笔记图标打开“阅读摘要”，已有摘要在重新打开助手时直接从本地显示。可返回原对话、手动更新、打开 Zotero 原生笔记。原对话、草稿及用于续聊的压缩记忆继续分别保存。

默认在完整回答保存后等待20秒空闲，使用当前选择的 AI 服务检查新增问答。首次覆盖旧会话，后续只处理新增部分。每次任务最多处理两批，自动模式在后续空闲继续；手动模式显示剩余状态，可点击“继续整理”。前台提问优先，取消后台生成；连接失败、格式无效、回答中断及超时均保留原摘要。摘要更新会额外使用当前服务额度，可在助手设置的“阅读摘要笔记”中关闭自动更新。

摘要正文、进度和笔记标识保存在原 PDF 同目录的对话 JSON 的 `readingSummary` 字段。独立 Zotero 笔记名为“阅读摘要 · PDF标题”，位于 PDF 所属文献下面；独立附件的笔记保存在相同文献库。正文支持公式，原生笔记使用 Zotero 数学节点。没有额外生成 Markdown 副本。关闭助手不会删除内容。

检测到用户改写或删除原生摘要笔记时，自动写入暂停，保留待合并候选。用户可查看候选后点击“保存摘要新版本”，人工原稿保留。原生笔记保存成功而 JSON 指针保存中断时，下一次依据当前 PDF 标记和 Zotero 规范化正文恢复已保存版本，避免重复建笔记。

### 安装

使用 `dist/margin-comments-deepseek-0.14.0.xpi` 从 Zotero 插件管理器覆盖安装，然后完全退出并重新打开 Zotero。无需先删除旧版。源码归档和包验证报告位于 `dist/`。本轮没有替用户修改实际安装。
