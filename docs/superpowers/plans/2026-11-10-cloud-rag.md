# Cloud Embedding RAG Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

Goal: 在当前 Zotero 文档助手中配置独立云端 Embedding，以本地可恢复的向量库搜索整个个人文献库，并将有出处的片段交给当前回答模型。

Architecture: 复用 papers-v1.sqlite 和既有历史来源，新增按端点隔离的加密配置、受限云端客户端、SQLite 派生缓存及 Worker 检索。RAG 协调器负责增量任务、前台预算、来源核验及融合；现有关键词模式与摘要功能继续可用。

Tech Stack: 项目现有 JavaScript IIFE/CommonJS、Zotero OSKeyStore/Prefs/DBConnection、Web Worker、Node test/SQLite、Playwright；不安装常驻数据库或本地推理模型。

## Global Constraints

活动目录 D:/AI Tool/zotero-margin-assistant；继续使用当前 checkout 的 feat/cloud-embedding-rag-0200 分支，不操作用户正在使用的 Zotero 或桌面。

默认服务 https://api.siliconflow.cn/v1/embeddings，模型 BAAI/bge-m3；允许自定义兼容端点。价格与限速由服务决定，不能自动切换收费模型。

首版默认每输入 8000 UTF-8 字节、每批 8 条、每分钟 20 次请求；前台语义检索附加预算 8000 ms；Worker 缓存预算 128 MiB。

最后最多三篇关联文献、6000 字符、每片段 1800 字符。没有可靠结果可返回空；语义命中不得再被纯字面 M.mergeSources 丢弃。

凭据按完整规范化 HTTPS 端点隔离并用 OSKeyStore 加密；固定测试短句测试连接。开始试建或全库前必须完成设置和连接测试，安装、保存或打开 PDF 不触发首次全库上传。

资料仅来自已提交的文本、合格正式摘要和完整历史问答；排除草稿、未完成回答、pendingText、memorySources 缓存和 Notion 网页。无 noteKey 的旧摘要保持原数据，云 RAG 标待核验。

持久向量 float32 可验证编码；来源和向量空间版本分开，更新立即使旧关联无效；失败、暂停、重启不删除有效索引。向量库使用独立 vectors-v1.sqlite。

先观察行为测试失败再实现。中间纯模块以针对性测试和独立审阅交付；产品集成与最终包必须完整 npm test、typecheck、隔离原生验收。不得将受控向量测试称为真实云端召回质量验证。

本计划接口中的 source 指 ZMAMemoryCore.cleanSources 接受的来源对象；namespace 已包含个人文献库身份和端点/模型/实际维度空间，input key 使用 SHA-256。

## Review Focus

切到未保存密钥的新端点时，空密码输入不得沿用旧端点 Key；已保存端点切回恢复自己的配置。

源文件或 generation 在云响应前后变化时，不得发布过期向量或把旧向量 ID 错配给新来源；SQLite 关联 ID 不得复用。

跨语言语义命中在原始问题没有共同字面词时，仍能进入最终请求，并保留来源身份及页号。

超过 Worker 缓存容量时必须继续分批扫描余下全库；取消和配置变更需要解除等待并忽略迟到回调。

初次保存/测试、重启暂停任务、没有密钥或断网时，不能意外开始全库上传，正常 PDF 对话和旧检索仍可用。

### Task 2: Vector codecs and bounded Worker search

Files: create src/vector-core.js, src/vector-runtime.js, content/rag-vector-worker.js; tests/vector-core.test.cjs and tests/vector-runtime.test.cjs.

Interfaces: ZMAVectors exports pack(vector), unpack(encoded, dimensions), cosine(query, vector), anchorKey(source), hybridSelect(candidates, query, options). pack normalizes finite nonzero vectors and returns {encoded, compact, norm, dimensions}: encoded is deterministic little-endian float32 Base64; compact is symmetric int8 Base64 with per-vector norm for approximate cosine, without modifying persistent floats. anchorKey depends on source identity/kind/conversation/message/part, not current text. hybridSelect takes internal scored candidates {source, denseRank?, sparseRank?, score?}, deduplicates, applies 3-paper/6000/1800 budgets and labels without requiring raw query token overlap. It must preserve dense-only matches and allow no results.

Methods invalidate() and destroy() clean promises and resources. Task 3 supplies rows; namespace/revision resets stale caches. Background worker uses explicit request IDs and ignores cancelled work. Worker file imports vector-core from the shipped chrome scripts URL.
