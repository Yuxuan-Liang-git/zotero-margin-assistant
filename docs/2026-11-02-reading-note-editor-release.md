# 0.14.1 阅读笔记整理

### 正文组织

阅读摘要现在按“文章内容、关键公式解释、补充讨论”维护整份笔记。“文章内容”说明研究对象、问题、方法、结论和适用范围；“关键公式解释”定义符号，衔接关键公式、条件与推导；“补充讨论”整理直观理解、例子、反例、条件边界及待核对之处。内容采用完整段落和简短标题，避免加粗、列表、问答摘录和更新日志。

编辑提示要求先判断新增问答是否带来新知识、澄清或纠正，再决定修改对应章节；重复提问和闲聊允许不更新。每次输出完整整合正文，消除矛盾和重复。遇到具体定义缺失，仅说明相应缺口，不把推断或模型曾经给出的解释直接写为论文结论。文献标题、年份和 DOI 等有限元数据随文字材料提供，用于交代阅读对象；这一步不额外上传 PDF 或图片。

原先的提示没有规定稳定章节和编辑决策，容易延续“新增问答C1”等对话式表述。本版改变编辑要求和结果协议；自动化能够验证结构与保存流程，生成质量仍依赖模型对具体材料的理解，不能由固定标题或模拟响应证明。

### 格式错误与旧摘要

有效结果直接采用 Markdown 正文，数学仍使用原有分隔符。无需把长篇公式嵌入 JSON 字符串；无更新时模型返回独立的无变化标记。保留正确旧 JSON 结果的兼容读取。缺少主章节、公式分隔符未闭合、连接中断或结果超过长度限制时保留旧笔记和待处理进度。Windows 换行、Markdown 与 JSON 围栏及公式中的 `\\[4pt]` 行间距经过回归验证。

旧版保存的摘要缺少新格式版本，将在下一次自动更新或手动点击“重新整理”时重组。即使旧问答已全部处理过，也会纳入本轮重整；较长历史仍分批处理。有效结果保存前保持原来的正文和进度，生成失败或取消不会清空它们。完成重整后回到增量编辑，当前未新增的问答不重复请求。人工改写、删除保护和另存新版本的行为继续保留。

安装本版后完全重启 Zotero，再打开阅读摘要，点击“重新整理”即可触发旧笔记重组。开启自动更新时也会在空闲后处理。整理仍使用当前所选 AI 服务的额度；此前的真实账户 HTTP400 若继续存在，也会导致生成失败，旧笔记会保留。本次开发没有改写用户当前文库中的笔记。
