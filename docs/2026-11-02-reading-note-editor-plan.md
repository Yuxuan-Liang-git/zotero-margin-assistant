# 阅读摘要改为独立阅读笔记

### 已明确的要求与根因

用户要求按“文章内容、关键公式解释、补充讨论”组织可独立阅读的笔记，按新增内容判断是否更新、更新什么和放在哪一节；不抄录对话过程，使用连贯散文。此要求是在既有摘要功能上直接指定修改，沿用当前JavaScript、保存机制及笔记入口，不另加确认轮次。

当前提示只要求合并旧摘要与单段问答，缺少稳定章节和编辑决策，允许保留“新增问答C1”等会话痕迹。parseResult强制JSON；带LaTeX的正文一旦用Markdown直接返回或JSON转义无效，就会触发截图中的解析错误。测试能够复现这类格式输入，但没有捕获本次实际服务响应，因此不把具体非法字符作为已确认事实。

### 方案与边界

只调整措辞不能修复JSON转义失败或更新已消费历史的旧摘要。选择完整笔记编辑协议：模型返回带三个主章节的Markdown正文，使用固定的独立标记表达无需修改；兼容正确的旧JSON结果。已有笔记、当前新增问答和文献标题等元数据作为资料；模型先判断新知识、纠正或重复，再重写受影响章节，输出完整整合正文。强调符号定义、条件、公式关系和结论依据；局部缺少来源时只在对应位置说明。继续限制输入长度、取消优先和每任务两批，不上传PDF或图片。

增加笔记格式版本，旧版摘要即使已经处理完全部问答，也会在下一次更新时重新整理。只在有效结果之后替换旧格式进度；失败、取消、人工改写和删除保护沿用原逻辑。旧问答不删除。没有对话时可依据旧笔记重整；没有任何资料时不凭空生成。

### 执行与验证

先添加失败回归，覆盖含LaTeX的直接Markdown、代码围栏、明确无变化、无效或截断输出、章节缺失、旧JSON兼容，以及提示的编辑要求、文章元数据和旧摘要迁移；然后修改reading-summary.js与Host适配器。对话状态格式仍为v2，readingSummary内增加formatVersion，不改变历史角色及原生数学节点。

更新浏览器和隔离原生夹具为三个主章节及直接Markdown，验证本地读取、公式显示、旧摘要重整、无变化跳过和手动改写保护。运行专项、完整npm test、全部src checkJs、确定性构建与包资源检查。原生配置保持隔离，测试模型响应模拟；独立最终审查关注迁移的进度和候选保存、格式误判及用户手工内容保护。打包0.14.1，文档记录测试证据和真实模型输出质量的验证边界。
